# 03 — 固件内 ext2 文件系统

`nflasha15` 解压后是 **ext2** 镜像（block size 1024，inode 128B）。

## 定位文件

- 超级块在偏移 1024；
- 块组描述符在 `(first_data_block+1)*block_size`；
- inode 表按组计算：`g=(ino-1)//inodes_per_group`；
- 目录项格式：`inode(u32), rec_len(u16), name_len(u8), type(u8), name`。

`tools/ext2_tool.py` 实现了最小遍历/读取。

## 只改内容、不改大小

提示音配置在：

```
/share/avsystemsound/beeplist.txt
```

格式：

```
BEEP_ID_FORCUSLOCK  0x0004  PIN  Dslr_Emnt_FocusLock.bin ...
BEEP_ID_SELECT      0x0008  APP  Dslr_Emnt_T_Select.bin ...
```

把 `FORCUSLOCK` 的文件名换成别的 `.bin` 即可“换音色”，但：

- ext2 无校验，**原地改字节安全**；
- 文件长度不变（用空格补齐），避免改 inode；
- 改完仍需重压 TPZL + 重算 CRC。

脚本：`tools/patch_beeplist.py`。
